## Задание №5: Передача сложных JSON-структур между сервисами

### Промпт 1

**Инструмент:** Codex  
**Промпт:** "Реализуй передачу сложной структуры заказа между двумя Go-сервисами: публичный API должен принимать заказ с клиентом, адресом, товарами и настройками доставки, затем отправлять JSON в сервис каталога и возвращать объединенный ответ клиенту."
